# 碳盤查考點與計算速查懶人包

本篇整理自 [[01_大專校院溫室氣體盤查實務指引]] 及環境部最新指引，彙整核心法規數字、經典計算題型與考試必考陷阱。

---

## ⚡ 1. 必背核心數字與法規時程

| 項目 | 核心關鍵字 / 數字 | 備註說明 |
| :--- | :--- | :--- |
| **大專校院納管門檻** | 全校用電合計 $\ge$ **2,000 萬度**<br>或單一校區 $\ge$ **1,000 萬度** | 滿足其一即列管（114/3/4 公告，115 年起實施） |
| **盤查時程** | 每年 **4 月 30 日前** | 登錄前一年度（1/1~12/31）數據至資訊平台 |
| **大專校院查驗要求** | **免查驗（0 家查驗機構）** | 採分級管理，與鋼鐵/半導體等製造業（10/31前查驗）不同 |
| **法定列管溫室氣體** | **7 種** | $\mathrm{CO_2, CH_4, N_2O, HFCs, PFCs, SF_6, NF_3}$ |
| **法規 GWP 版本** | **IPCC AR5** (百年尺度) | $\mathrm{CO_2}=1, \mathrm{CH_4}=28, \mathrm{N_2O}=265$ |
| **資料保存年限** | **至少 6 年** | 各項單據、帳冊、抄表紀錄皆須備查 |

## 🎯 2. 常考「陷阱題」辨析表

| 情境題 | 是否納入盤查？ | 原因分析 |
| :--- | :---: | :--- |
| 校內有獨立商工登記之 7-11 / 星巴克 | ❌ **排除** | 屬獨立登記商業主體，由其自行申報，避免學校重複計算 |
| 學校附設醫院（有獨立醫事機構代碼） | ❌ **排除** | 依目的主管機關各自邊界辦理 |
| 校長搭高鐵或計程車出差 | ❌ **不列入強制盤查** | 屬 [[溫室氣體範疇|範疇三]]，環境部目前僅強制盤查範疇一與二 |
| 學校委外長期租賃的校車 | ❌ **不列入範疇一** | 租賃車輛屬於範疇三；僅「學校名下自有公務車」算範疇一 |
| 建築物已接公共污水下水道之化糞池 | ❌ **免計算 (0)** | 污水已由公共污水處理廠處理，校園化糞池免計 |
| 校園走廊配備的 ABC 乾粉滅火器 | ❌ **免計算 (0)** | 主要成分磷酸二氫銨，化學反應不產生 $\mathrm{CO_2}$ |
| 自設太陽能光電自發自用 | ⭕ **計入，但係數為 0** | 發電過程無直接溫室氣體排放，揭露度數但排碳量為 0 |

## 🧮 3. 典型計算題公式精粹

### 題型一：外購電力排放量（[[排放係數法]]）
$$\text{排放量 (公噸 } \mathrm{CO_2e}) = \frac{\text{總用電度數 (度)}}{1,000} \times \text{電力排碳係數 (如 0.474 公斤/度)}$$

### 題型二：固定燃料燃燒（柴油發電機 / 瓦斯爐）
$$\text{排放量 (公噸 } \mathrm{CO_2e}) = \text{用量} \times \text{低位熱值} \times 4.1868 \times 10^{-9} \times \text{排放係數 (kg/TJ)} \times \mathrm{GWP} \div 1000$$

### 題型三：冷媒逸散（[[逸散排放]]）
$$\text{排放量 (公斤 } \mathrm{CO_2e}) = \text{銘牌冷媒充填量 (kg)} \times \text{運行逸散率 (\%/年)} \times \frac{\text{當年度使用天數}}{365 \text{ 或 } 366} \times \mathrm{GWP}$$
