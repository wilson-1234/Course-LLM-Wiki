# ISO 14067 產品碳足跡標準

> [!NOTE] 白話費曼比喻
> [[ISO 14064-1]] 量的是「一整間公司或整座工廠」的總排碳量；
> 而 **ISO 14067** 量的是「單一商品（例如這罐可樂、這支手機）」從原料開採、製造、運輸到最後丟棄，身上到底背了多少公克的碳！

---

## 一、組織碳盤查 vs 產品碳足跡對比

| 比較維度 | ISO 14064-1 (組織盤查) | ISO 14067 (產品碳足跡) |
| :--- | :--- | :--- |
| **計算對象** | 整個企業／機構／廠區 | 單一產品或服務（宣告單位 Functional Unit） |
| **時間維度** | 一個日曆年度（如 2024 年全年度） | 產品的全生命週期（Life Cycle） |
| **評估邊界** | 組織邊界（控制權法／股權法） | 搖籃到大門 (B2B) 或 搖籃到墳墓 (B2C) |
| **主要用途** | 企業 ESG 揭露、法規申報、碳費申報 | 碳標籤申請、供應鏈綠色採購、低碳商品設計 |
